# ChatGPT channel fact sheet

Last full check: **2026-11-11** (sections S, O, C, copied from the read-only `chatgpt-channel-skills` set) and **2026-11-13** (section A, the Ads API facts the MCP server and the skills rely on). Every skill in this repository cites the fact ids below.

How to read it:

- **Checked** is the day the source was last read.
- **Confidence** says how the fact was established:
  - `doc` = read in the vendor's own documentation on that day. Not run against a live store or ad account.
  - `observed` = seen by us live on that day: on public pages (sections S, O, C) or through the API on an ad account (section A). Not documented by the vendor, so it can change without notice, and one account or a few stores is a small sample.
  - `secondary` = reported by a third party. The primary source could not be read.
  - `unconfirmed` = could not be established. A skill must check it live or report "could not check".
- If a fact is older than 60 days, re-check the source before relying on it and tell the user the fact was stale.
- A field name that is not in this sheet must not be used. Look it up in the linked reference first.
